# Aura 100% Definitive Trading AI - APK Conversion Guide
(মোবাইলে APK তৈরি করার সম্পূর্ণ নির্দেশিকা)

এই প্রজেক্টটি খুব সহজেই সরাসরি অ্যান্ড্রয়েড APK ফাইলে রূপান্তর করা যায়:

---

### পদ্ধতি ১: Website 2 APK Builder দিয়ে (সবচেয়ে সহজ - ১ মিনিট)
1. আপনার কম্পিউটারে "Website 2 APK Builder" সফটওয়্যারটি ইনস্টল করুন।
2. "Web URL" অথবা "Local HTML" অপশন বেছে নিয়ে এই ফোল্ডারের ফাইলগুলো সিলেক্ট করুন।
3. App Name: **Aura Trading Assistant**
4. "Generate APK" বাটনে ক্লিক করলেই আপনার ফোনে ইন্সটলযোগ্য .apk ফাইল তৈরি হয়ে যাবে!

---

### পদ্ধতি ২: মোবাইলেই সরাসরি PWA অ্যাপ ইনস্টল (কোনো পিসি লাগবে না)
1. মোবাইল ক্রোম ব্রাউজারে অ্যাপটির লাইভ লিঙ্ক ওপেন করুন।
2. ক্রোমের উপরের ডানপাশের ৩টি ডটে (Menu) চাপ দিন।
3. **"Install app"** বা **"Add to Home screen"** সিলেক্ট করুন।
4. সাথে সাথে আপনার মোবাইলের হোম স্ক্রিনে ফুলস্ক্রিন নেটিভ অ্যান্ড্রয়েড অ্যাপের মতো আইকন চলে আসবে!

---

### পদ্ধতি ৩: Capacitor / Cordova দিয়ে ফুল APK তৈরি
```bash
npm install
npm run build
npx cap init "Aura Trading" "com.auratrading.app"
npx cap add android
npx cap open android
# Android Studio তে "Build APK" ক্লিক করুন
```
